### 2. Thực hành tạo VPC ⏱️ 2h
- **Mô tả**: Sử dụng AWS VPC Wizard để tạo VPC với 2 public subnets và 2 private subnets. Cấu hình route tables, internet gateway, NAT gateway cho private subnets.
- **Kết quả**: VPC hoạt động đúng với các thành phần mạng cơ bản, hiểu flow traffic trong VPC.
- **Tools/Tech**: AWS VPC, Route Tables, NAT Gateway, Internet Gateway
- **Links**: 
- [Amazon VPC](https://000003.awsstudygroup.com/)


### 3. Tìm hiểu Security Groups vs NACLs ⏱️ 1h
- **Mô tả**: So sánh Security Groups (stateful) và Network ACLs (stateless).
- **Kết quả**: Hiểu rõ sự khác biệt và khi nào dùng cái nào.
- **Tools/Tech**: AWS Security Groups, Network ACLs
- **Links**:
