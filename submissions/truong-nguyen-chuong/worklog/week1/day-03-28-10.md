### 2. Thực hành launch và kết nối EC2 instance ⏱️ 2.5 giờ
- **Mô tả**: Launch EC2 instance t2.micro với Amazon Linux 2 AMI. Cấu hình Security Group cho phép SSH (port 22) và HTTP (port 80). Tạo key pair, download .pem file, set permissions (chmod 400). Connect vào instance qua SSH trên terminal.
- **Kết quả**: EC2 instance chạy thành công, có public IP, Kết nối SSH thành công vào server, Có thể thực thi các command cơ bản trên EC2
- **Tools/Tech**: AWS EC2 Console, Amazon Linux 2, Key Pair (.pem), Security Group, SSH, Terminal / PuTTY


### 3. Tìm hiểu EBS và Instance Store ⏱️ 0.5 giờ

- **Kết quả**: Biết khi nào dùng EBS, khi nào dùng instance store.
- **Tools/Tech**: AWS EBS Documentation

## 🚧 Khó khăn và giải pháp

### Vấn đề 1: SSH connection refused
- **Mô tả**: Lỗi "Connection refused" khi try SSH vào EC2
- **Ảnh hưởng**: Không thể access instance
- **Nguyên nhân gốc rễ**: Security Group không allow port 22 từ my IP
- **Cách giải quyết**: Check Security Group rules, add rule for SSH từ my IP (0.0.0.0/0 chỉ để test)
- **Kết quả sau khi giải quyết**: SSH thành công
- **Bài học rút ra**: Luôn check Security Groups khi có network issues
