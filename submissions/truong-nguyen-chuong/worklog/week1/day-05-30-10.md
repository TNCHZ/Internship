## 💼 Công việc đã thực hiện

### 1. Nghiên cứu IAM Fundamentals ⏱️ 1 giờ
- **Mô tả**: Tìm hiểu về IAM concepts: users, groups, roles, policies. Hiểu sự khác biệt giữa authentication và authorization.
- **Kết quả**: Nắm vững IAM terminology và concepts.
- **Tools/Tech**: AWS IAM Documentation
- **Links**: 
  - [IAM User Guide](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html) 


### 2. Thực hành tạo IAM user ⏱️ 1 giờ
- **Mô tả**: Tạo IAM user mới cho team member, set console password và access keys. Enable MFA cho user này.
- **Kết quả**: User được tạo thành công với appropriate permissions.
- **Tools/Tech**: AWS IAM Console


### 3. Tạo IAM group và policies ⏱️ 1.5 giờ
- **Mô tả**: Tạo group "Developers" với policy cho phép access EC2, S3 read-only. Thêm user vào group.
- **Kết quả**: Group-based permission management hoạt động.
- **Tools/Tech**: IAM Policies, JSON editor


### 4. Tìm hiểu IAM Roles ⏱️ 0.5 giờ
- **Mô tả**: Nghiên cứu về IAM roles cho EC2 instances và cross-account access. Hiểu use case của roles vs users.
- **Kết quả**: Biết khi nào dùng roles, khi nào dùng users.
- **Tools/Tech**: IAM Roles Documentation
- **Links**:
  - [IAM Roles Tutorial](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles.html)

## 🚧 Khó khăn và giải pháp

### Vấn đề 1: Policy JSON syntax error
- **Mô tả**: Lỗi cú pháp JSON khi tự viết custom policy
- **Ảnh hưởng**: Policy không thể save
- **Nguyên nhân gốc rễ**: Thiếu dấu phẩy, dấu ngoặc
- **Cách giải quyết**: Dùng policy validator, copy từ managed policies và modify
- **Kết quả sau khi giải quyết**: Policy created successfully
- **Bài học rút ra**: Luôn validate policy trước khi save
