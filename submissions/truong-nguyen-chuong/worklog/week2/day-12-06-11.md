### 2. Thiết kế chức năng gửi email trong User Service ⏱️ 1h
- **Mô tả**:
  - Xác định các trường hợp User Service cần gửi email:
    - Gửi OTP xác thực email khi đăng ký
    - Gửi OTP / link reset password khi quên mật khẩu
  - Thiết kế `EmailService` riêng biệt:
    - `sendOtpEmail(email, otp)`
    - `sendResetPasswordEmail(email, token)`
  - Phân tách rõ trách nhiệm:
    - User Service: xử lý nghiệp vụ
    - Email Service: chỉ lo gửi email
- **Kết quả**:
  - Có thiết kế service rõ ràng, dễ test và mở rộng
  - Tránh hard-code logic gửi mail trong controller
- **Tools/Tech**: Spring Boot, Service Layer Design

### 3. Phân tích luồng gửi email trong nghiệp vụ User Service ⏱️ 1h
- **Mô tả**:
  - Phân tích luồng gửi email cho từng nghiệp vụ:
    - **Đăng ký**:
      1. User submit thông tin
      2. Lưu user (chưa active)
      3. Sinh OTP
      4. Lưu OTP vào Redis
      5. Gửi email OTP
    - **Quên mật khẩu**:
      1. User nhập email
      2. Kiểm tra user tồn tại
      3. Sinh token / OTP
      4. Gửi email reset password
  - Ghi chú các điểm cần lưu ý:
    - Timeout OTP
    - Retry gửi mail nếu lỗi
- **Kết quả**:
  - Luồng nghiệp vụ rõ ràng, dễ chuyển sang code
- **Tools/Tech**: Sequence Diagram (phác thảo nhanh)

### 4. Chuẩn bị cấu hình email cho giai đoạn triển khai ⏱️ 0.5h
- **Mô tả**:
  - Xác định các biến cấu hình cần thiết:
    - `spring.mail.host`
    - `spring.mail.port`
    - `spring.mail.username`
    - `spring.mail.password`
  - Quyết định:
    - Không commit thông tin SMTP thật
    - Dùng `application-local.yml` cho môi trường dev
- **Kết quả**:
  - Sẵn sàng cấu hình khi bắt đầu coding
- **Tools/Tech**: Spring Boot Config
