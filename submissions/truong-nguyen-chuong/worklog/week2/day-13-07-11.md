### 2. Cấu hình Project Structure & Conventions ⏱️ 1.5h
- **Mô tả**: Tạo project structure theo layered architecture:
    ```
    src/main/java/com/eventhub/userservice/
    ├── config/           # Configuration classes
    ├── controller/       # REST controllers
    ├── service/          # Business logic
    ├── repository/       # Data access layer
    ├── pojo/           # JPA entities
    ├── dto/             # Data Transfer Objects
    ├── filter/        # JWT
    ├── util/            # Utilities
    └── UserServiceApplication.java
    ```
    - Cấu hình checkstyle, spotless cho code formatting.
    - Setup Git hooks với Husky (pre-commit check).
    - Tạo `.gitignore` đầy đủ (target/, .idea/, *.properties, etc.).
- **Kết quả**: Project structure rõ ràng, coding standards defined.
- **Tools/Tech**: Checkstyle, Spotless, Git.

### 3. Setup Docker Compose cho Local Development ⏱️ 1.5h
- **Mô tả**: Tạo `docker-compose.yml` để chạy PostgreSQL và Redis:
    ```yaml
    version: '3.8'
    services:
      postgres:
        image: postgres:15-alpine
        environment:
          POSTGRES_DB: user_service
          POSTGRES_USER: admin
          POSTGRES_PASSWORD: admin123
        ports:
          - "5432:5432"
        volumes:
          - postgres_data:/var/lib/postgresql/data
      
      redis:
        image: redis:7-alpine
        ports:
          - "6379:6379"
        command: redis-server --appendonly yes
        volumes:
          - redis_data:/data
    ```
    - Test kết nối với `psql` và `redis-cli`
    - Tạo `application-dev.properties` cho dev profile
- **Kết quả**: Chạy `docker-compose up` thành công, services ready.
- **Tools/Tech**: Docker, Docker Compose, PostgreSQL CLI, Redis CLI.

## 🚧 Khó khăn và giải pháp

### Vấn đề: Spring Boot 3.x yêu cầu Jakarta EE thay vì javax
- **Mô tả**: Khi thêm dependency cho JWT (jjwt), các import `javax.servlet.*` bị lỗi.
- **Ảnh hưởng**: Không thể compile project.
- **Nguyên nhân gốc rễ**: Spring Boot 3.x migrated từ Java EE (javax) sang Jakarta EE (jakarta).
- **Cách giải quyết đã áp dụng**:
    1. Tìm dependency tương thích: `io.jsonwebtoken:jjwt-api:0.12.3` (hỗ trợ Jakarta)
    2. Sử dụng import `jakarta.servlet.*` thay vì `javax.servlet.*`
    3. Update tất cả annotations: `@jakarta.persistence.*`, `@jakarta.validation.*`
- **Kết quả sau khi giải quyết**: Project compile thành công.
- **Bài học rút ra**: Luôn check compatibility khi dùng phiên bản mới. Spring Boot 3.x có breaking changes.
