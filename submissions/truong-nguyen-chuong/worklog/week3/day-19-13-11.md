## 💼 Công việc đã thực hiện

### 1. Thiết kế giao diện Frontend Authentication ⏱️ 1.5 giờ
- **Mô tả**:
  - Thiết kế UI/UX cho các chức năng authentication chính:
    - Modal **Login**
    - Xử lý trạng thái **Logout / Session expired**
  - Định nghĩa luồng xử lý khi user:
    - Chưa đăng nhập
    - Đăng nhập thành công
    - Token hết hạn
- **Kết quả**:
  - Có bản thiết kế rõ ràng cho frontend authentication flow
  - Dễ dàng map sang logic backend JWT
- **Tools/Tech**: NextJS, Figma (concept), Ant Design / Bootstrap

### 2. Kết nối & Test API Authentication Backend → Frontend ⏱️ 2 giờ
- **Mô tả**:
  - Kết nối frontend với API login từ User Service:
    - `POST /api/v1/auth/login`
  - Xử lý response:
    - Nhận `token`
    - Lưu token phía frontend (cookie)
  - Gắn JWT vào header cho các request tiếp theo:
    - `Authorization: Bearer <token>`
  - Test các case:
    - Login thành công
    - Login sai password
    - Gọi API khi chưa có token
- **Kết quả**:
  - Frontend gọi API backend thành công
  - JWT được lưu và sử dụng đúng cho các request authenticated
  - Xác nhận backend auth hoạt động đúng từ góc nhìn frontend
- **Tools/Tech**: NextJS, Axios, Spring Boot (User Service), JWT

### 3. Xử lý Logout & Session Handling ⏱️ 0.5 giờ
- **Mô tả**:
  - Implement logout flow phía frontend:
    - Clear access token
    - Reset authentication state
    - Redirect về trang login
  - Xử lý trường hợp token hết hạn:
    - API trả về 401
    - Tự động logout và yêu cầu đăng nhập lại
- **Kết quả**:
  - Logout hoạt động đúng
  - Tránh được các lỗi UI khi token không hợp lệ
- **Tools/Tech**: React Context / Hooks, Axios Interceptors
