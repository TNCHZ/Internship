## 💼 Công việc đã thực hiện

### 1. Thiết kế giao diện Login / Logout ⏱️ 1.5 giờ
- **Mô tả**:
  - Thiết kế UI cho trang **Login**:
    - Input email / username
    - Input password
    - Button đăng nhập
    - Hiển thị message lỗi từ backend
  - Thiết kế logic **Logout**:
    - Clear token khỏi storage
    - Redirect về trang login
  - Đảm bảo UI đơn giản, dễ mở rộng cho OTP / Reset Password sau này
- **Kết quả**:
  - Hoàn thiện giao diện login responsive
  - UX rõ ràng, xử lý trạng thái loading & error
- **Tools/Tech**: NextJS, Axios, CSS / Tailwind

---

### 2. Kết nối Frontend với API Authentication ⏱️ 1.5 giờ
- **Mô tả**:
  - Kết nối frontend với API đăng nhập từ User Service
  - Gửi request login (email + password)
  - Nhận JWT token từ backend
  - Lưu token vào `cookie`
  - Cấu hình Axios interceptor để tự động attach token vào header:
    ```
    Authorization: Bearer <JWT>
    ```
- **Kết quả**:
  - Frontend gọi API backend thành công
  - Nhận và lưu JWT token đúng format
  - Các API protected có thể truy cập sau khi login
- **Tools/Tech**: Axios, JWT, Spring Boot Backend

---

### 3. Test End-to-End Authentication Flow ⏱️ 1 giờ
- **Mô tả**:
  - Test các case:
    - Login đúng → thành công
    - Login sai password → hiển thị lỗi
    - Token hết hạn → redirect về login
    - Logout → token bị xoá
  - Verify backend logs và frontend behavior
- **Kết quả**:
  - Authentication flow hoạt động đúng
  - Không phát hiện bug nghiêm trọng
  - Ready cho mở rộng OTP & refresh token
- **Tools/Tech**: Browser DevTools, Spring Boot Logs
