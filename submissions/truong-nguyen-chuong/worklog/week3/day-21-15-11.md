### 1. Thiết kế giao diện OTP Verification ⏱️ 1.2 giờ
- **Mô tả**:
  - Thiết kế UI màn hình **OTP Verification**:
    - Input OTP 6 chữ số
    - Countdown thời gian sống của OTP
    - Button xác nhận OTP
    - Hiển thị trạng thái OTP hết hạn / sai OTP
  - Đảm bảo UI thống nhất với Login page
- **Kết quả**:
  - UI rõ ràng, dễ sử dụng
  - Sẵn sàng mở rộng cho reset password
- **Tools/Tech**: React, CSS / Tailwind

---

### 2. Kết nối và test API OTP ⏱️ 1.3 giờ
- **Mô tả**:
  - Gọi API verify OTP từ backend
  - Gửi OTP người dùng nhập
  - Nhận response thành công / thất bại
  - Xử lý các case:
    - OTP hợp lệ
    - OTP sai
    - OTP hết hạn
- **Kết quả**:
  - OTP verification hoạt động đúng
  - Frontend phản hồi đúng theo trạng thái backend
- **Tools/Tech**: Axios, Spring Boot OTP API

---

### 3. Implement Protected Routes ⏱️ 1 giờ
- **Mô tả**:
  - Xây dựng cơ chế bảo vệ route:
    - Kiểm tra token trước khi render page
    - Redirect về login nếu chưa xác thực
  - Tạo `PrivateRoute` / `AuthGuard`
  - Kiểm tra token khi reload trang
- **Kết quả**:
  - Các trang private không truy cập được khi chưa login
  - UX mượt, không flash UI
- **Tools/Tech**: React Router, JWT

---

### 4. Hoàn thiện Authentication Flow ⏱️ 0.5 giờ
- **Mô tả**:
  - Chuẩn hoá flow:
    - Login → OTP → Access protected pages
    - Logout → clear token → redirect login
  - Kiểm tra toàn bộ flow end-to-end
- **Kết quả**:
  - Authentication flow hoàn chỉnh
  - Sẵn sàng cho reset password & refresh token
- **Tools/Tech**: React, Spring Boot
