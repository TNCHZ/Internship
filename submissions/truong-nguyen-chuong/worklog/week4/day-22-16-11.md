## 💼 Công việc đã thực hiện

### 1. Học và ghi chú Module 04 – Dịch vụ lưu trữ trên AWS ⏱️ 2.5h
- **Mô tả**:
    - Xem toàn bộ nội dung Module 04, tập trung vào các dịch vụ lưu trữ cốt lõi của AWS:
        - **Amazon S3 (Simple Storage Service)**: Object storage, tính bền vững (11 9s), versioning, lifecycle rule.
        - **Amazon EBS (Elastic Block Store)**: Block storage cho EC2, snapshot, performance tiers.
        - **Amazon EFS (Elastic File System)**: File storage dùng chung cho nhiều EC2.
        - **AWS Glacier**: Lưu trữ dữ liệu dài hạn, archive, tối ưu chi phí.
    - Phân tích **use case thực tế** cho từng loại storage:
        - S3: upload avatar, lưu ảnh sự kiện, static assets.
        - EBS: database, application runtime.
        - EFS: chia sẻ file giữa các service.
        - Glacier: log cũ, backup, dữ liệu lưu trữ lâu dài.
- **Kết quả**:
    - Hoàn thiện bộ ghi chú chi tiết, có phân loại rõ ràng theo:
        - Loại lưu trữ
        - Mục đích sử dụng
        - Ưu / nhược điểm
        - Chi phí tương đối
- **Giá trị học được**:
    - Storage là **nền tảng của kiến trúc hệ thống**, ảnh hưởng trực tiếp đến:
        - Hiệu năng
        - Khả năng mở rộng
        - Chi phí vận hành
    - Không phải mọi dữ liệu đều nên lưu ở cùng một loại storage.
