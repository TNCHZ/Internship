## 💼 Công việc đã thực hiện

### 1. Học Module 06 – AWS Database Services ⏱️ 18:00 – 22:00

#### 📌 Nội dung đã học
- **Tổng quan các dịch vụ cơ sở dữ liệu trên AWS**
  - Phân loại:
    - Relational (RDS, Aurora)
    - NoSQL (DynamoDB)
    - In-memory (ElastiCache)
    - Data Warehouse (Redshift)
- **Amazon RDS**
  - Các engine: MySQL, PostgreSQL, MariaDB, Oracle, SQL Server
  - Khái niệm:
    - Multi-AZ
    - Read Replica
    - Automated Backup & Snapshot
- **Amazon Aurora**
  - Kiến trúc shared storage
  - Hiệu năng cao hơn RDS truyền thống
  - Use cases cho hệ thống lớn, cần HA
- **Amazon DynamoDB**
  - Key-value & Document database
  - Partition key, sort key
  - On-demand vs Provisioned capacity
  - Use case: session, metadata, high-scale systems
- **Amazon ElastiCache**
  - Redis vs Memcached
  - Use case: caching, OTP, session, leaderboard
- **So sánh lựa chọn Database**
  - Khi nào dùng RDS
  - Khi nào dùng DynamoDB
  - Khi nào cần cache (Redis)
