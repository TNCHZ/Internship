## 💼 Công việc đã thực hiện

### 1. Rà soát backend APIs và xử lý lỗi tiềm ẩn ⏱️ 2h
- **Mô tả**:
    - Review lại các API quan trọng (Auth, User):
        - Kiểm tra response status code có đúng REST semantics không
        - Chuẩn hoá error response (message, errorCode, timestamp)
    - Fix các vấn đề thường gặp:
        - NullPointerException do thiếu validate request body
        - Trả về `200 OK` cho case lỗi logic → đổi sang `400/401/403`
        - Bổ sung default value cho các field optional
    - Kiểm tra ảnh hưởng cross-service:
        - Đảm bảo API không break các service đang consume
        - Kiểm tra backward compatibility cho frontend

- **Kết quả**:
    - Backend ổn định hơn, predictable behavior
    - Error handling rõ ràng, dễ debug cho frontend
    - Giảm rủi ro lỗi runtime khi tích hợp service

- **Tools/Tech**: Spring Boot, Spring Validation, REST API review.

---

### 2. Tăng cường validate dữ liệu Backend ↔ Frontend ⏱️ 1.5h
- **Mô tả**:
    - **Backend validation**:
        - Sử dụng `@NotNull`, `@NotBlank`, `@Email`, `@Size`
        - Validate chặt ở DTO thay vì để lỗi rơi vào service layer
        - Custom message cho các validation errors
    - **Frontend-side alignment**:
        - Rà soát lại payload frontend gửi lên
        - Đồng bộ field name, data type, format (email, UUID, date)
    - **Error contract**:
        - Thống nhất format lỗi frontend có thể parse & hiển thị
        - Tránh các lỗi không rõ nguyên nhân với user

- **Kết quả**:
    - Giảm lỗi 400 không rõ nguyên nhân
    - Frontend dễ xử lý form validation và hiển thị lỗi
    - API boundary rõ ràng hơn giữa FE và BE

- **Bài học**:
    > Validate không chỉ để “chặn lỗi”, mà để **giao tiếp rõ ràng giữa các layer**.

---

### 3. Kiểm thử luồng tích hợp Frontend ↔ Backend ⏱️ 0.5h

    - Quan sát:

    - Backend phản hồi nhất quán hơn
    - Frontend xử lý lỗi mượt và rõ ràng hơn
