## 💼 Công việc đã thực hiện

### 1. Nghiên cứu API Gateway Pattern trong Microservices ⏱️ 1.5h
- **Mô tả**:
    - Tìm hiểu vai trò của API Gateway trong hệ thống microservices:
        - Single entry point cho frontend
        - Giảm coupling giữa frontend và backend services
        - Centralized concerns: routing, security, rate limiting
    - So sánh API Gateway với việc frontend gọi trực tiếp từng service:
        - Ưu điểm: đơn giản hoá frontend, kiểm soát traffic tốt hơn
        - Nhược điểm: Gateway trở thành critical component
    - Tham khảo các mô hình Gateway phổ biến:
        - Backend for Frontend (BFF)
        - Edge Gateway
        - Cloud-native Gateway (AWS API Gateway, GCP API Gateway)

- **Kết quả**:
    - Hiểu rõ lý do cần API Gateway trong hệ thống EventHub
    - Có định hướng rõ ràng khi thiết kế gateway cho nhiều service

---

### 2. Làm quen và thử nghiệm Spring Cloud Gateway ⏱️ 1.5h
- **Mô tả**:
    - Tạo service `api-gateway` để thử nghiệm Spring Cloud Gateway
    - Thực hành các khái niệm chính:
        - Route
        - Predicate (Path-based routing)
        - Filter (pre-filter, post-filter)
    - Cấu hình gateway để route request đến các backend services:
        - User Service
        - Page Service
        - AIChat Service
    - Test routing bằng Postman để quan sát luồng request/response

- **Kết quả**:
    - Nắm được cách Gateway xử lý request
    - Hiểu rõ cách frontend chỉ cần làm việc với một endpoint duy nhất
    - Có cái nhìn thực tế về độ phức tạp của cấu hình Gateway

- **Tools/Tech**: Spring Cloud Gateway, YAML configuration, Postman.

---

### 3. Ôn tập Best Practices về API Security ⏱️ 1h
- **Mô tả**:
    - Rà soát lại các nguyên tắc bảo mật API:
        - Authentication vs Authorization
        - Không trust client
        - Validate input ở mọi layer
    - Tìm hiểu vai trò của API Gateway trong security:
        - Forward JWT token đến backend services
        - Có thể validate token ở Gateway hoặc ở service
    - Nhận diện các rủi ro:
        - Missing Authorization header
        - Public endpoints bị abuse
        - DDoS hoặc brute-force API calls

- **Kết quả**:
    - Hiểu rõ security responsibility giữa Gateway và Backend services
    - Có định hướng rõ ràng cho việc xử lý JWT và rate limiting trong tương lai
