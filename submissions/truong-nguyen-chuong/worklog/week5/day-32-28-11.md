## 💼 Công việc đã thực hiện

### 1. End-to-End Testing qua API Gateway ⏱️ 1.5h
- **Mô tả**:
    - Test các luồng chính của hệ thống thông qua Gateway:
        - Đăng nhập người dùng
        - Gọi API cần xác thực
        - Gọi API public (không cần token)
    - Kiểm tra hành vi của Gateway trong các trường hợp:
        - Request hợp lệ
        - Request thiếu JWT token
        - JWT token không hợp lệ / hết hạn
    - So sánh response khi:
        - Gọi trực tiếp backend service
        - Gọi thông qua API Gateway

- **Kết quả**:
    - Gateway hoạt động đúng vai trò trung gian
    - Frontend chỉ cần cấu hình một base URL duy nhất
    - Phát hiện một số khác biệt về HTTP status khi lỗi xảy ra (401 vs 403)

- **Bài học**:
    > End-to-end testing giúp phát hiện vấn đề mà test từng service riêng lẻ không thấy được.

---

### 2. Rà soát Security Flow (JWT & API Access) ⏱️ 1.5h
- **Mô tả**:
    - Phân loại lại API endpoints:
        - **Public APIs**: login, register, health check
        - **Protected APIs**: user profile, event management, chat
    - Kiểm tra luồng JWT:
        - Frontend gửi JWT trong Authorization header
        - Gateway forward token đến backend services
        - Backend service validate token và phân quyền
    - Đánh giá 2 hướng tiếp cận:
        - Validate JWT ở Gateway
        - Validate JWT ở từng service (hiện tại)

- **Nhận xét**:
    - Validate JWT ở service giúp service độc lập hơn
    - Gateway vẫn có thể kiểm tra format token để filter request sớm
    - Security nên được chia đều theo tầng, không dồn vào một điểm

- **Kết quả**:
    - Hiểu rõ security boundary giữa Gateway và Services
    - Có cơ sở để đề xuất cải tiến security architecture

---

### 3. Làm quen với Monitoring & Logging cho Gateway ⏱️ 1h
- **Mô tả**:
    - Enable Spring Boot Actuator cho API Gateway
    - Khám phá các endpoint:
        - `/actuator/health`
        - `/actuator/metrics`
        - `/actuator/gateway/routes`
    - Quan sát các metrics cơ bản:
        - Request count
        - Response status
        - Gateway routing info
    - Nhận diện tầm quan trọng của logging:
        - Debug routing issues
        - Theo dõi lỗi từ downstream services

- **Kết quả**:
    - Nắm được cách theo dõi trạng thái Gateway
    - Có định hướng tích hợp Prometheus/Grafana sau này
