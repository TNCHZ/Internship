## 💼 Công việc đã thực hiện

### 1. Tìm hiểu tổng quan Amazon ECR ⏱️ 1h
- **Mô tả**:
  - Đọc tài liệu AWS về:
    - Khái niệm ECR
    - Private vs Public ECR
    - Workflow: Docker build → tag → login → push
  - So sánh ECR với Docker Hub:
    - Authentication bằng IAM
    - Tích hợp tốt với ECS / EKS
- **Hiểu được**:
  - ECR là nơi lưu trữ image, **không tự build**
  - Mỗi service nên có **repository riêng**
  - Image tag đóng vai trò rất quan trọng cho deployment
- **Tools/Tech**: AWS Docs, Docker concepts

---

### 2. Thực hành tạo repository và push image ⏱️ 2h
- **Các bước đã làm**:
  1. Tạo ECR repository trên AWS Console
  2. Build Docker image local cho User Service
  3. Thực hiện `aws ecr get-login-password` để login
  4. Tag image theo format ECR
  5. Push image lên ECR
- **Kết quả**: ❌ **Chưa push thành công**
- **Lỗi gặp phải**:
  - `denied: User is not authorized to perform ecr:InitiateLayerUpload`
  - `no basic auth credentials`
- **Nhận xét**:
  - Workflow nhiều bước
  - Chỉ cần sai 1 bước là fail toàn bộ

---

### 3. Debug & tìm nguyên nhân ⏱️ 1h
- **Các hướng đã thử**:
  - Kiểm tra lại IAM User / Role
  - Gán policy `AmazonEC2ContainerRegistryFullAccess`
  - Kiểm tra region giữa AWS CLI và ECR
  - Re-login nhiều lần
- **Vấn đề nhận ra**:
  - IAM & permissions **phức tạp hơn tưởng tượng**
  - Chưa hiểu rõ:
    - Khác nhau giữa IAM User vs Role
    - Khi nào dùng access key local
    - Khi nào dùng role cho CI/CD
- **Kết quả**: Vẫn chưa push thành công, quyết định dừng để tổng hợp lại kiến thức
