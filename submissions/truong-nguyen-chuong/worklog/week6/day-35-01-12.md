### 2. Xác định nguyên nhân gốc rễ lỗi ECR ⏱️ 0.5h
- **Root Cause Analysis**:
  - IAM User local có Access Key nhưng **policy chưa đủ** để thao tác với ECR
  - AWS CLI đang cấu hình sai **region** so với repository
- **Lỗi cũ**:
  - `no basic auth credentials`
  - `not authorized to perform ecr:InitiateLayerUpload`
- **Tools/Tech**: AWS CLI, CloudTrail (quick check)
- **Links**:
  - [Troubleshooting Amazon ECR authentication](https://docs.aws.amazon.com/AmazonECR/latest/userguide/rest-api-authorization.html)
- **Kết luận**: Cần cập nhật policy phù hợp và đăng nhập ECR đúng region

---

### 3. Áp dụng giải pháp & cấu hình lại IAM ⏱️ 1h
- **Các bước thực hiện**:
  1. Kiểm tra và cập nhật region bằng `aws configure`
  2. Gán policy cần thiết:
     - `AmazonEC2ContainerRegistryFullAccess` (tạm thời cho lab)
  3. Login ECR với token tạm thời:
     ```bash
     aws ecr get-login-password --region ap-southeast-1 \
       | docker login --username AWS --password-stdin <account-id>.dkr.ecr.ap-southeast-1.amazonaws.com
     ```
  4. Build & tag image:
     ```bash
     docker build -t user-service .
     docker tag user-service:latest <account-id>.dkr.ecr.ap-southeast-1.amazonaws.com/user-service:latest
     ```
  5. Push image:
     ```bash
     docker push <account-id>.dkr.ecr.ap-southeast-1.amazonaws.com/user-service:latest
     ```
- **Tools/Tech**: Docker, AWS CLI
- **Links**:
  - [Getting started with Amazon ECR (CLI)](https://docs.aws.amazon.com/AmazonECR/latest/userguide/getting-started-cli.html)
- **Kết quả**: ✅ **Push image lên ECR thành công**
