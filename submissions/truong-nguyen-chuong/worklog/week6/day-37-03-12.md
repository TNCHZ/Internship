## 💼 Công việc đã thực hiện

### 1. Phân tích chi phí CloudFront ⏱️ 1.5h
- **Mô tả**:
  - Tìm hiểu các thành phần chi phí:
    - Data transfer out (egress)
    - HTTP/HTTPS requests
    - Invalidation requests
  - So sánh truy cập trực tiếp ALB vs qua CloudFront
- **Tools/Tech**: Cost Explorer (concept), CloudFront pricing docs
- **Links**:
  - [CloudFront Pricing & Cost Savings](https://aws.amazon.com/cloudfront/pricing/)
- **Kết quả**:
  - CloudFront **giảm chi phí tổng thể** trong nhiều kịch bản, dù có chi phí riêng
- **Insight quan trọng**:
  > Dùng CDN là chuyển chi phí từ “nhiều request đắt” sang “nhiều request rẻ”

---

### 2. Học chiến lược cache để tối ưu chi phí ⏱️ 1.5h
- **Mô tả**:
  - Tìm hiểu chiến lược cache:
    - Cache static content lâu (images, assets)
    - Cache API responses có kiểm soát (stale-while-revalidate, short TTL)
    - Hạn chế invalidation; dùng versioning khi có thể
  - Nhận diện anti-patterns: TTL quá ngắn, invalidate liên tục
- **Tools/Tech**: curl, browser devtools, sample S3 responses
- **Links**:
  - [CloudFront Caching and TTLs](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/Expiration.html)
  - [HTTP Caching (MDN)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Caching)
- **Kết quả**:
  - Hiểu cache strategy trực tiếp ảnh hưởng đến bill cuối tháng
- **Best practices rút ra**:
  - Version assets thay vì invalidate
  - Thiết kế headers (Cache-Control) ngay từ backend
