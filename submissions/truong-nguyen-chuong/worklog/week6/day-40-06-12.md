- **Kết quả**: Hiểu rõ **ALB hoạt động ở tầng Application (HTTP/HTTPS)**

---

### 2. Phân tích Application Load Balancer chi tiết ⏱️ 1.5h
- **Mô tả**:
  - Nghiên cứu các thành phần ALB: Listeners, Rules (host/path-based), Target Groups, Health checks
  - Hiểu cách ALB route theo path/domain và hỗ trợ advanced routing
- **Tools/Tech**: AWS Console, ALB Developer Guide
- **Links**:
  - [Application Load Balancers (ALB) — Overview](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/introduction.html)
  - [Listener rules and routing](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/listener-update-rules.html)
- **Kết quả**: ALB là trung tâm điều phối cho microservices và route logic

---

### 3. So sánh ALB vs NLB trong thực tế ⏱️ 0.5h
- **So sánh rút ra**:

| Tiêu chí | ALB | NLB |
|---|---:|---:|
| OSI Layer | Layer 7 | Layer 4 |
| Giao thức | HTTP / HTTPS | TCP / UDP |
| Routing | Path, Host | IP + Port |
| Use case | Web, API, Microservices | High-performance, low latency |

- **Kết luận**: Web/API → ALB; Real-time/streaming → NLB

---

### 4. Liên hệ ALB với kiến trúc tổng thể ⏱️ 1h
- **Mô tả**:
  - Vẽ flow: User → Route 53 → CloudFront → ALB → Target Groups (EC2 / ECS)
  - Phân tích role của mỗi tầng (CDN vs LB vs service)
- **Tools/Tech**: draw.io, CloudFront docs
- **Links**:
  - [Amazon CloudFront Overview](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/Introduction.html)
- **Kết quả**: ALB là “cửa phân phối logic” của backend — kết hợp tốt với CDN & DNS
