### 2. Tạo workflow build Docker image ⏱️ 1.5h
- **Mô tả**: Viết workflow để checkout code, build Docker image, prepare để push (chưa push vì chưa setup AWS).
- **Kết quả**: Basic workflow hoạt động, image được build thành công locally.
- **Tools/Tech**: GitHub Actions, Docker, Node.js
- **Workflow content**:
  ```yaml
  name: CI - Build Docker Image
  
  on:
    push:
      branches:
        - main
        - develop
  
  jobs:
    build:
      runs-on: ubuntu-latest
      
      steps:
        - name: Checkout code
          uses: actions/checkout@v3
        
        - name: Set up Docker Buildx
          uses: docker/setup-buildx-action@v2
        
        - name: Build Docker image
          run: |
            docker build -t user-service:${{ github.sha }} .
            docker build -t user-service:latest .
        
        - name: List built images
          run: docker images | grep user-service
  ```
- **Status**: ✅ Workflow runs successfully, images build correctly
- **Links**: [GitHub Actions Docker Guide](https://docs.github.com/en/actions/publishing-packages/publishing-docker-images)

### 3. Attempted AWS Integration ⏱️ 1.5h
- **Mô tả**: Cố gắng integrate GitHub Actions với AWS ECR. Nghiên cứu aws-actions/configure-aws-credentials, OIDC setup, nhưng gặp nhiều lỗi cấu hình.
- **Kết quả**: Gặp lỗi, chưa thể push tới ECR. Xác định được các vấn đề cần fix ngày mai.
- **Tools/Tech**: AWS IAM, GitHub Actions, ECR, aws-actions
- **Workflow attempted** (không hoạt động):
  ```yaml
  - name: Configure AWS credentials
    uses: aws-actions/configure-aws-credentials@v2
    with:
      role-to-assume: arn:aws:iam::123456789012:role/github-actions-role
      aws-region: ap-southeast-1
  
  - name: Login to ECR
    run: aws ecr get-login-password --region ap-southeast-1 | docker login --username AWS --password-stdin ${{ env.ECR_REGISTRY }}
  ```
- **Errors encountered**:
  - ❌ `InvalidIdentityToken` - OIDC provider chưa setup
  - ❌ `AccessDenied` - ECR permissions chưa configure
  - ❌ `ECR_REGISTRY` env variable undefined
- **Links**: [aws-actions/configure-aws-credentials](https://github.com/aws-actions/configure-aws-credentials)
