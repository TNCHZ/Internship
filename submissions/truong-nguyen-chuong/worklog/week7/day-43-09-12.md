## 💼 Công việc đã thực hiện

### 1. CloudFormation Fundamentals Learning ⏱️ 1.5h
- **Mô tả**: Tìm hiểu CloudFormation basics - templates, stacks, resources, parameters, outputs. Học về YAML vs JSON, intrinsic functions, resource references.
- **Kết quả**: Hiểu được CloudFormation fundamentals, ready để viết templates.
- **Tools/Tech**: AWS CloudFormation, CloudFormation Designer, AWS documentation
- **Key concepts đã học**:
  - **Templates**: Declarative JSON/YAML files define AWS resources
  - **Stacks**: Instance của template, manage lifecycle tất cả resources
  - **Resources**: AWS services (VPC, EC2, RDS, ECR, etc)
  - **Parameters**: Input values cho stack
  - **Outputs**: Export values từ stack
  - **Mappings**: Hard-coded values dựa conditions
  - **Intrinsic Functions**: `!Ref`, `!Sub`, `!GetAZs`, etc
- **Links**: [AWS CloudFormation User Guide](https://docs.aws.amazon.com/cloudformation/latest/userguide/)

---

### 2. Tạo VPC Template (gặp lỗi) ⏱️ 1.5h
- **Mô tả**: Viết CloudFormation template (YAML) để provision VPC. Gặp multiple syntax errors, indentation issues, undefined resources.
- **Kết quả**: Template có structure nhưng gặp validation errors. Xác định được các vấn đề cần fix.
- **Tools/Tech**: CloudFormation, YAML, AWS VPC
- **Template attempted** (có lỗi):
  ```yaml
  AWSTemplateFormatVersion: '2010-09-09'
  Description: VPC with Public and Private Subnets
  
  Parameters:
    EnvironmentName:
      Type: String
      Default: production
  
  Resources:
    VPC:
      Type: AWS::EC2::VPC
      Properties:
        CidrBlock: 10.0.0.0/16  # ❌ String phải được quote
        EnableDnsHostnames: true
    
    InternetGateway:
      Type: AWS::EC2::InternetGateway
    
    AttachGateway:
      Type: AWS::EC2::VPCGatewayAttachment
      Properties:
        VpcId: !Ref VPC
        InternetGatewayId: !Ref InternetGateway
    
    PublicSubnet1:
      Type: AWS::EC2::Subnet
      Properties:
        VpcId: !Ref VPC
        CidrBlock: 10.0.1.0/24
        AvailabilityZone: !Select [0, !GetAZs '']  # ❌ Quotes issue
  
  Outputs:
    VpcId:
      Value: !Ref VPC  # ❌ Missing Export section
  ```
- **Errors encountered**:
  - ❌ `YAML syntax error`: Improper quoting of CIDR blocks
  - ❌ `ValidationError`: GetAZs parameter format incorrect
  - ❌ `Property validation failed`: Missing required properties
  - ❌ `Circular dependency`: Resource references unclear
- **Links**: [CloudFormation Template Anatomy](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/template-anatomy.html)

## 🚧 Khó khăn và giải pháp

### Vấn đề 1: YAML syntax errors
- **Mô tả**: Indentation issues, missing quotes, incorrect syntax
- **Ảnh hưởng**: CloudFormation rejects template before even validating
- **Nguyên nhân gốc rễ**: YAML sensitive to whitespace, CloudFormation specific rules
- **Cách giải quyết**: Use cfn-lint locally, reference AWS examples (ngày mai)
- **Kết quả**: Chưa fix (work in progress)
- **Bài học rút ra**: Validate YAML syntax locally trước deploy

### Vấn đề 2: CloudFormation property names
- **Mô tả**: Property names typos hoặc incorrect format
- **Ảnh hưởng**: Template validation fails
- **Cách giải quyết**: Reference AWS CloudFormation documentation carefully
- **Bài học rút ra**: AWS documentation specific về exact property names

### Vấn đề 3: Circular dependencies
- **Mô tả**: Resources reference each other creating circular dependencies
- **Ảnh hưởng**: CloudFormation cannot determine creation order
- **Cách giải quyết**: Restructure template, use DependsOn (ngày mai)
- **Bài học rút ra**: Plan resource relationships upfront
