### 1. Chi tiết Hóa Thiết kế Subnet ⏱️ 1.5h
- **Mô tả**: Xác định rõ mục đích từng subnet, CIDR blocks, AZ distribution
- **Kết quả**: Subnet planning chi tiết, ready for infrastructure setup
- **Subnet Design**:
  ```
  VPC: 10.0.0.0/16 (65,536 IP addresses)
  
  AZ-1 (ap-southeast-1a):
  ├─ Public Subnet: 10.0.1.0/24 (256 IPs)
  │  └─ Purpose: ALB, NAT Gateway
  │  └─ Route: 0.0.0.0/0 → IGW
  │
  └─ Private Subnet RDS: 10.0.11.0/24 (256 IPs)
     └─ Purpose: RDS Primary instance
     └─ Route: 0.0.0.0/0 → NAT Gateway
  
  AZ-2 (ap-southeast-1b):
  ├─ Public Subnet: 10.0.2.0/24 (256 IPs)
  │  └─ Purpose: ALB (multi-AZ), NAT Gateway
  │  └─ Route: 0.0.0.0/0 → IGW
  │
  └─ Private Subnet ECS: 10.0.12.0/24 (256 IPs)
     └─ Purpose: ECS Tasks (Fargate)
     └─ Route: 0.0.0.0/0 → NAT Gateway
  ```
- **CIDR Planning Logic**:
  - Public subnets (1, 2): Cho ALB, NAT Gateway
  - Private subnets (11, 12): Cho ECS tasks và RDS
  - Naming convention: `1X.0.Y.0/24` (X=AZ, Y=tier)
  - Room for expansion: Có thể thêm subnets 3, 4, 13, 14 nếu cần
- **Tools/Tech**: CIDR calculator, AWS console planning
- **Links**: [AWS Subnet Planning Guide](https://docs.aws.amazon.com/vpc/latest/userguide/VPC_Subnets.html)

### 2. Lên Danh sách Security Groups ⏱️ 1.5h
- **Mô tả**: Xác định security groups cho mỗi tier, inbound/outbound rules
- **Kết quả**: Security group configuration chi tiết
- **Security Groups**:
  1. **ALB-SG** (Application Load Balancer):
     - Inbound: 
       - Port 80 (HTTP): 0.0.0.0/0
       - Port 443 (HTTPS): 0.0.0.0/0
     - Outbound: All traffic to ECS-SG
     - Mục đích: Receive traffic từ internet
  
  2. **ECS-SG** (ECS Tasks):
     - Inbound:
       - Ports (service-specific): ALB-SG
       - Port 5432 (PostgreSQL): RDS-SG (for local connections if needed)
     - Outbound:
       - All traffic (necessary for external API calls, AWS services)
     - Mục đích: Run microservices, communicate with RDS
  
  3. **RDS-SG** (PostgreSQL Database):
     - Inbound:
       - Port 5432: ECS-SG
     - Outbound: None (typically restricted)
     - Mục đích: Database access từ ECS only
  
  4. **NAT-GW-SG** (Optional, tinh chỉnh)
     - Inbound: Port 0.0.0.0/0 (all traffic)
     - Outbound: 0.0.0.0/0 (all traffic)
- **Security Principles**:
  - ALB ← Internet
  - ECS ← ALB (not directly from internet)
  - RDS ← ECS (not from internet, not from ALB)
  - NAT allows ECS → Internet
- **Tools/Tech**: AWS Security Groups, network security best practices

### 3. IAM Roles cho ECS Tasks ⏱️ 0.5h
- **Mô tả**: Xác định IAM roles/policies cho ECS tasks chạy services
- **Kết quả**: IAM permission model, principle of least privilege
- **IAM Setup**:
  1. **ECS Task Execution Role** (`ecsTaskExecutionRole`):
     - Pull images từ ECR
     - Push logs tới CloudWatch
     - Retrieve secrets từ Secrets Manager
     - Policy: `AmazonECSTaskExecutionRolePolicy`
  
  2. **ECS Task Role** (`ecsTaskRole` - per service):
     - **User Service Role**:
       - Secrets Manager: Read user service secrets
       - CloudWatch: Write logs
     - **Event Service Role**:
       - SNS/SQS: Publish event notifications
       - S3: Read/write event media
     - **AI Chat Service Role**:
       - Bedrock/OpenAI: Call AI APIs
       - CloudWatch: Write logs
     - **Payment Service Role**:
       - SNS: Send payment confirmations
       - Secrets Manager: Read payment secrets
  
  3. **RDS Proxy Role** (if using RDS Proxy):
     - Access RDS
     - KMS: Decrypt credentials
- **Trust Relationship**:
  ```json
  {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Effect": "Allow",
        "Principal": {
          "Service": "ecs-tasks.amazonaws.com"
        },
        "Action": "sts:AssumeRole"
      }
    ]
  }
  ```
- **Tools/Tech**: AWS IAM, principle of least privilege

### 4. Vẽ Chi tiết Traffic Flows ⏱️ 0.5h
- **Mô tả**: Tạo sơ đồ chi tiết 3 traffic flows chính
- **Kết quả**: Sơ đồ rõ ràng cho implementation reference
- **Traffic Flow 1: External User → ECS**
  ```
  User (203.0.113.0) → Internet → IGW (10.0.0.0/16)
  → ALB (Public Subnet 10.0.1.0/24)
  → Target Group (ECS in Private 10.0.12.0/24)
  → ECS Task (microservices)
  ```
- **Traffic Flow 2: ECS → External APIs**
  ```
  ECS Task (10.0.12.100) → Private Subnet Route Table
  → NAT Gateway (10.0.1.50) [Public Subnet]
  → IGW
  → External API (e.g., OpenAI API)
  ```
- **Traffic Flow 3: ECS → RDS**
  ```
  ECS Task (10.0.12.100) → RDS Security Group
  → RDS Endpoint (10.0.11.0/24)
  → PostgreSQL queries
  ```
- **Tools/Tech**: Lucidchart, AWS architecture diagrams
