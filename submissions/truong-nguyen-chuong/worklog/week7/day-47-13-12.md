### 1. Tạo CloudFormation Template cho VPC ⏱️ 3h
- **Mô tả**: Tạo Infrastructure as Code cho kiến trúc VPC toàn bộ
- **Kết quả**: CloudFormation template hoàn chỉnh, ready to deploy
- **Template Key Components**:
  - **VPC**: 10.0.0.0/16 với DNS enabled
  - **Public Subnets**: 10.0.1.0/24 (AZ-1), 10.0.2.0/24 (AZ-2)
  - **Private Subnets**: 10.0.11.0/24 (RDS), 10.0.12.0/24 (ECS)
  - **Internet Gateway**: Route 0.0.0.0/0 → IGW
  - **NAT Gateways**: 1 per AZ, with Elastic IPs
  - **Route Tables**: Public (2) and Private (2)
  - **Security Groups**: ALB-SG, ECS-SG, RDS-SG
  - **Outputs**: VPC ID, Subnet IDs, SG IDs cho cross-stack references

- **CloudFormation Features Used**:
  - **Parameters**: Configurable environment name, CIDR blocks
  - **Mappings**: Optional, för multi-region support later
  - **Conditions**: For conditional resource creation
  - **Outputs**: Export values cho ECS/RDS stacks
  - **Tags**: Applied consistently across all resources
  - **DependsOn**: Explicit dependencies (IGW before routes)
  - **Metadata**: Documentation and AWS::CloudFormation::Init (optional)

- **Template Validation**:
  - Valid CloudFormation YAML/JSON
  - All required properties included
  - cfn-lint validation passed
  - Manual review for best practices

- **Tools/Tech**: CloudFormation, YAML, AWS Console, cfn-lint
- **File Location**: `infrastructure/vpc/vpc-stack.yaml`
- **Links**: 
  - [CloudFormation VPC Resources](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-properties-ec2-vpc.html)
